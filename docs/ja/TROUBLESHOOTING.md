| 問題 | 推奨する対処 |
|---|---|
| 外部ツールに Power Portal がない | 管理者としてインストールを完了し、Desktop を閉じて開き直し、[登録場所](CONFIGURATION.md#external-tools-registration)を確認してください。公式インストーラーを再実行して修復します。 |
| 外部ツールリボン自体がない | Power BI Desktop のエディション/バージョンを IT 部門と確認してください。このパッケージは外部ツールに対応する Desktop 向けで、Service や Report Server 向けではありません。 |
| 外部ツールが起動しなくなった | Desktop を再起動してください。実行ファイルが移動またはブロックされた可能性があります。再インストールしてパスを修復します。登録引数の先頭の `--` を手動削除しないでください。 |
| モデル未読込 / 接続失敗 | Desktop で PBIX を開いて外部ツールから起動するか、**開いているモデルを検索**を選んでください。Desktop 再起動後は古いローカルポートが失効するため、再接続します。 |
| ファイル名が違う / モデルが複数ある | 目的の開いているモデルを明示的に選び、書き込み前に確認対象を検証してください。ウィンドウタイトルは完全なパスを省略する場合があります。 |
| 生の PBIX のインポートが失敗する | Power BI で PBIX を開き、ローカル接続してください。読み取り専用ファイルのインポートには BIM/PBIP/TMDL/ZIP を使用します。 |
| テーマダイアログがまだ出る | 想定どおりです。Desktop のテーマインポートは可視の UI Automation を使用します。このリリースにサポートされたダイアログ不要の汎用テーマ API はありません。 |
| テーマ自動化が失敗する | 生成した JSON を保存し、対象ウィンドウを確認し、インポート中は操作せず、Power BI のテーマメニューから手動インポートしてください。PBIX をアップロードせず、正確なエラーと Desktop バージョンを報告します。 |
| 既存テーマがモデルとともに読み込まれない | Desktop で現在のテーマ JSON を保存し、テーマジェネレーターにインポートしてください。TOM はレポートテーマを読めません。 |
| HTML メジャーはあるがビジュアルが表示されない | 対応する HTML ビジュアルを追加し、メジャーを手動で割り当ててください。 |
| カレンダーにまだ行がない | Desktop でモデルを更新し、再読み取りしてください。DAX/日付範囲を確認します。 |
| カレンダーを元に戻す操作が拒否される | テーブルが変わったか依存関係があります。削除を強制せず、保存した PBIX コピーを使うか、メタデータバックアップをもとに支援を求めてください。 |
| 再インストールしても言語が変わらない | 既存ユーザーの保存した選択はインストールの既定値より優先されます。サイドバーの国旗を変更してください。 |
| 既定言語の設定が無効 | アプリを閉じ、管理者に `powerportal-defaults.json` を対応コードの有効な UTF-8 JSON に修正してもらってください。 |
| PowerShell スクリプトがブロックされる | スクリプトを確認し、組織の実行ポリシーに従ってください。代わりに EXE ウィザードも使えます。企業の制御を無効化しないでください。 |
| `-Silent` が管理者の PowerShell を要求する | そのターミナルを閉じ、PowerShell を**管理者として実行**して再試行してください。 |
| SHA-256 が一致しない | **ファイルを実行しないでください。**無効なダウンロードを削除/移動し、公式添付ファイルを再取得して公開チェックサムと比較します。 |
| GitHub のダウンロードが失敗する | 接続、プロキシ/ファイアウォールの制限、Release URL を確認してください。IT 部門は検証済み EXE を承認された経路で配布できます。 |
| PowerShell が基になる接続/TLS 送信エラーを報告する | Windows PowerShell で補助スクリプトを取得する前に、記載の TLS 1.2 の行を使用して再試行してください。ネイティブアプリの更新プログラムは独立して HTTPS/TLS を使用しています。 |
| SmartScreen/発行元不明 | 1.8.0 は未署名です。チェックサムと発行元を確認し、未署名プログラムがブロックされる端末では IT 部門に相談してください。 |
| リレーションシップエディターが読み取り専用 | プロジェクトのインポートでは表示の整理のみ可能です。作成/編集/削除にはライブのローカル Power BI モデルに接続してください。 |
| 読み取り後にリレーションシップが変わった | Power BI モデルを再読み取りし、新しいつながりを確認してください。他の変更の上書きを防ぐため古い編集は拒否します。 |
| 重複または 2 つ目の有効リレーションシップ | 異なる列のペアを使うか、別の関係を有効化する前に、そのテーブル間の現在の有効リレーションシップを無効化してください。 |
| リレーションシップの型/一意性/曖昧性エラー | 列のデータ型を一致させ、Desktop でキー/フィルターパスを確認してください。TOM/Power BI がモデルを検証します。エラーを回避しないでください。 |
| マップの保存が失敗する | アプリプロファイルのディスク容量と書き込み権限を確認し、「保存を再試行」を使用してください。必要なら別の JSON コピーをエクスポートします。 |
| PBIX の名前変更/コピー後にマップが異なる | プロファイルはウィンドウ/ファイル名とテーブルの系列タグを使用し、コピー間で名前/識別子が変化または衝突する場合があります。エクスポートしたレイアウトを目的のモデルにインポートしてください。 |
| 起動時に更新を確認しない | 1.6.1 以前は一度手動で 1.6.2 に更新する必要があります。開発/ソースからの実行は意図的に更新しません。 |
| 更新チェック失敗/オフライン/HTTP 403 または 429 | ローカルツールは使用できます。インターネット/プロキシ/ファイアウォールを確認し、**更新を確認**を再試行してください。GitHub API のレート制限が適用される場合があります。 |
| 今すぐ更新のチェックサム/サイズ検証が失敗する | インストーラーは実行されていません。再試行するか公式 Release を手動ダウンロードしてください。破損したキャッシュファイルを実行しないでください。 |
| Windows の承認をキャンセルした | Power Portal は引き続き利用できます。UAC を承認する準備ができたら**今すぐ更新**を再試行するか、IT 部門にインストール権限を求めてください。 |
| モデル操作の実行中で更新できない | 確認済みの書き込み/テーマ操作の完了を待ち、再試行してください。更新前に未送信の編集を保存/エクスポートします。 |
| 起動時の接続通知がない | 検出には開いているローカルセマンティックモデルが必要で、Desktop の開始画面だけでは不十分です。PBIX を開いて**開いているモデルを検索**を使用してください。検出失敗時は表示されたエラーを確認し再接続します。 |
| インストーラーが実行中のアプリを終了できない | 作業を保存し、Power Portal を手動で閉じて再試行してください。対象はインストールされた正確な実行ファイルのみです。Power BI は閉じません。 |
| メールボタンが動作しない | 既定のメールクライアントを設定するか、**メールアドレスをコピー**を使うか、下のアドレスに手動でメールしてください。 |
| オンライン TV レポートにサインインできない/読み込めない | Microsoft アカウント、レポート権限、ライセンス、埋め込み制限、インターネットを確認してください。オフライン TV にはローカル画像を使用します。 |

<a name="contact-support"></a>
## サポートへの連絡

**[contato@consultoriaexcelencia.com.br](mailto:contato@consultoriaexcelencia.com.br)** にメールするか、[WhatsApp で Excelência に連絡](https://api.whatsapp.com/send/?phone=5535998532286&text&type=phone_number&app_absent=0)してください。

次の情報を含めてください。

- Power Portal のバージョン（このリリースは 1.8.0）。
- Windows バージョンと Power BI Desktop のバージョン/エディション。
- インストール方法（ウィザードまたは PowerShell）。
- 再現手順と画面に表示された正確なエラー。
- 開いていたモデルが 1 つか複数か。

**PBIX/BIM ファイル、ソース接続情報、資格情報、機密データ、機密情報未除去のバックアップ/変更ログを公開 issue に投稿しないでください。**画像にも名前やデータが写る場合があります。共有前に機密箇所を隠してください。

展開や機密事項は公開 issue ではなくサポートメールを使用してください。
