## 言語とサイドバーの設定

サイドバーの国旗で言語を切り替えます。設定は Windows ユーザーのローカルアプリプロファイルに保存されます。サイドバーの折りたたみ/展開状態も保存します。

対応するウィンドウサイズでは、11 個すべてのツールボタンがサイドバーのスクロールなしで表示されます。長い翻訳ラベルは最大 2 行で表示し、完全なアクセシブル名/ツールチップを保持します。**コンサルティングと研修**は**開発について**の下にあります。[展開/折りたたみ状態の画像](SCREENSHOTS.md#home-and-navigation)。

言語の優先順位：

1. アプリで保存した選択。
2. インストール先の `powerportal-defaults.json`。
3. Windows/Electron のシステムロケール。未対応の言語は英語。

| コード | 言語 |
|---|---|
| `pt` | ポルトガル語（ブラジル） |
| `en` | 英語 |
| `es` | スペイン語 |
| `zh` | 標準中国語 / 簡体字中国語 |
| `fr` | フランス語 |
| `ja` | 日本語 |
| `hi` | ヒンディー語 |
| `ar` | アラビア語、右から左 |

インストーラーは選択されたアプリのインストール先にこのファイルを書き込みます。

```json
{"language":"en"}
```

管理者は Power Portal を閉じてからファイルを編集し、**新しいユーザープロファイル**の既定値を変更できます。対応する言語コードを正確に指定し、有効な UTF-8 JSON で保存してください。アプリのバイナリやパッケージ資源は編集しないでください。無効な設定は明示的に報告されます。

インストール時の既定値を変更したり再インストールしたりしても、既存ユーザーが保存した国旗の選択は上書きしません。モデル名、データ、コード、DAX 式は翻訳しません。

<a name="connect-to-an-open-power-bi-file"></a>
## 開いている Power BI ファイルへの接続

推奨：Power BI Desktop で PBIX を開き、**外部ツール > Power Portal** を起動してください。Desktop がローカルモデルのエンドポイントとデータベース識別子を自動的に渡します。

Windows ショートカットから起動する場合：

1. Power BI Desktop で PBIX を開きます。
2. 開いているローカルモデルを検出すると起動通知が表示されます。**開いているモデルを検索**でファイル名を選びます。
3. 変更後は**Power BI モデルを読み取る**でメタデータを再読み込みします。

検出は利用可能なモデルの一覧を示すだけで、ファイルの自動選択や書き込みは行いません。接続後、コンパクトな緑色のヘッダー状態が確認付きの調整を示します。**Power BI モデルを更新**でメタデータを再読み込みしてください。[接続の画像](SCREENSHOTS.md#connect-to-a-file-already-open-in-power-bi)。

開いているモデルが 1 つなら、読み取り時に自動検出できます。複数ある場合は目的のファイルを明示的に選んでください。似たファイル名は番号で区別します。Power BI のウィンドウタイトルに完全なパスが出るとは限りません。

接続はローカル専用です。公開サーバーを設定したり、モデルのポートを共有したり、リモート DAX サーバーとして扱ったりしないでください。Power BI を再起動した場合は、新しいローカルインスタンスに再接続してください。

<a name="external-tools-registration"></a>
## 外部ツールの登録

インストーラーは次に書き込みます。

```text
%CommonProgramFiles(x86)%\Microsoft Shared\Power BI Desktop\External Tools\PowerPortal.pbitool.json
```

登録にはインストールされた実行ファイルのパスと、次の Desktop プレースホルダーが含まれます。

```text
-- --powerportal-server "%server%" --powerportal-database "%database%"
```

先頭の `--` は意図的なものです。削除したり古いポートに手動置換したりしないでください。インストールや登録の修復後に Power BI Desktop を再起動してください。

<a name="data-locations"></a>
## データの保存場所

通常のアプリプロファイル：

```text
%APPDATA%\powerportal-desktop
```

関連するサブフォルダー：

- `themes`：生成された JSON と `.applied.json` の検証用エクスポート。
- `model-changes`：確認済み書き込みの試行と結果を記録したローカルデータ。
- `relationship-diagrams`：モデルごとの表示レイアウト。テーブル/グループ名、アイコン、色、位置、ビューポートを含みます。[リレーションシップマップ](RELATIONSHIPS.md#save-and-share-the-organization)からレイアウトをエクスポート/インポートできます。モデル書き込みは行いません。
- `updates`：検証済みの更新インストーラー。処理された失敗では部分ダウンロードを削除します。検証済みインストーラーはインストール後に残る場合がありますが、モデルバックアップではありません。
- ユーザーごとの UI 設定もプロファイルに保存されます。

メタデータバックアップはローカルに保存され、書き込み成功後に正確なパスを表示します。エクスポートしたドキュメントやダウンロード/生成ファイルは、ユーザーが選んだ保存先を使用します。

バックアップ、ログ、エクスポートは機密として扱ってください。完全な BIM バックアップにはソース/接続情報が、変更ログには変更前後の DAX が含まれる場合があります。アンインストール時に自動削除しません。公開の issue にアップロードしないでください。

UI 設定をリセットするには、アプリで別の言語を選ぶかサイドバーを展開します。プロファイル全体をリセットすると、保持されたログやバックアップも削除される場合があります。アプリを閉じ、必要なものを意図的に保存してからでなければ、プロファイルを削除しないでください。

<a name="network-and-accounts"></a>
## ネットワークとアカウント

- ローカルプレビューと同梱ツールには Power Portal アカウントは不要です。
- インストール済みアプリは起動時に公開 GitHub リリースメタデータを確認します。**今すぐ更新**の後、メインプロセスの更新プログラムが HTTPS で公式添付ファイルを取得します。更新要求にモデル名、式、行、資格情報は含みません。
- モデルにアクセスできるローカルウィンドウは、任意のリモート Web 要求をブロックします。
- コンサルティングのリンクと動画は、要求時に既定のブラウザーで開きます。
- TV Tool は公開 Power BI/Microsoft ページ用の隔離されたオンラインプレゼンテーションウィンドウを使用します。ローカルモデルへのアクセスは共有しません。Microsoft ログインは別で、セッション間で保持しません。
- DirectQuery は Power BI 経由で元のソースにアクセスし、ネットワークと既存のソース資格情報が必要な場合があります。
- メールには設定済みのメールクライアントが必要です。ない場合は**メールアドレスをコピー**を使用してください。

インストール時に API キー、パスワード、ポータル資格情報、ソースコード設定ファイルを提供する必要はありません。

## ウェルカム画面と保存される起動設定

ホームで、Power BI Desktop のファイルを開き、開いているモデルを検索し、対応する変更を確認して送信する手順を説明します。「起動するたびに表示する」は初期状態でオンです。オフにすると次回起動時に紹介を非表示にします。「ツールへ進む」は今回の紹介のみ閉じます。ホームの「ようこそ」から再表示し、スイッチを有効にできます。設定は Store 版とは別のローカルプロファイルに保存します。8 言語とキーボード操作に対応。画面を開くだけではモデルは変更しません。事前にコピーを作り、操作後に Power BI で PBIX を保存してください。実際のプロセス再起動、設定保持、モデル検索、多言語レイアウトをテストしました。モデル操作は模擬で、実データは変更していません。
