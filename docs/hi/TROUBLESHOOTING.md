| समस्या | सुझाई गई कार्रवाई |
|---|---|
| External Tools में Power Portal नहीं है | व्यवस्थापक के रूप में स्थापना पूरी करें, Desktop बंद करके दोबारा खोलें और [पंजीकरण स्थान](CONFIGURATION.md#external-tools-registration) जाँचें। आधिकारिक इंस्टॉलर फिर चलाकर सुधारें। |
| External Tools रिबन ही नहीं है | IT से अपने Power BI Desktop संस्करण/संस्करण-प्रकार की जाँच करें। यह पैकेज External Tools समर्थित Desktop संस्करणों के लिए है, Service या Report Server के लिए नहीं। |
| External Tool अब नहीं खुलता | Desktop फिर शुरू करें; स्थापित निष्पादन योग्य स्थानांतरित या अवरुद्ध हो सकता है। पथ सुधारने के लिए फिर इंस्टॉल करें। पंजीकरण तर्कों में शुरुआती `--` स्वयं न हटाएँ। |
| मॉडल लोड नहीं हुआ / कनेक्शन विफल | Desktop में PBIX खोलकर External Tools से लॉन्च करें या **Find open models** चुनें। Desktop फिर शुरू होने पर दोबारा कनेक्ट करें; पुराने स्थानीय पोर्ट समाप्त हो जाते हैं। |
| गलत फ़ाइल नाम / कई मॉडल | इच्छित खुले मॉडल को स्पष्ट रूप से चुनें और लिखने से पहले पुष्टि का लक्ष्य जाँचें। विंडो शीर्षक में पूरा पथ छूट सकता है। |
| Raw PBIX आयात विफल | PBIX को Power BI में खोलें और स्थानीय रूप से कनेक्ट करें। समर्थित केवल-पठन फ़ाइल आयात के लिए BIM/PBIP/TMDL/ZIP उपयोग करें। |
| Theme डायलॉग अब भी दिखता है | यह अपेक्षित है: Desktop theme आयात दृश्य UI Automation उपयोग करता है। इस रिलीज़ में डायलॉग के बिना सामान्य theme API समर्थित नहीं है। |
| Theme स्वचालन विफल | बनाया JSON रखें, लक्षित विंडो जाँचें, आयात के दौरान कुछ न करें और Power BI के Themes मेनू से स्वयं आयात करें। PBIX अपलोड किए बिना सटीक त्रुटि और Desktop संस्करण बताएँ। |
| मॉडल से मौजूदा theme लोड नहीं हुई | Desktop में मौजूदा theme JSON सहेजकर theme generator में आयात करें। TOM रिपोर्ट theme नहीं पढ़ सकता। |
| HTML माप है लेकिन विज़ुअल नहीं दिखता | संगत HTML विज़ुअल स्वयं जोड़ें और माप असाइन करें। |
| कैलेंडर में अभी पंक्तियाँ नहीं हैं | Desktop में मॉडल रीफ़्रेश करें, फिर दोबारा पढ़ें। DAX/तारीख़ सीमा जाँचें। |
| कैलेंडर वापस हटाना अस्वीकार हुआ | तालिका बदल गई है या उसकी निर्भरताएँ हैं। जबरन न हटाएँ; सहेजी PBIX प्रति उपयोग करें या मेटाडेटा बैकअप के साथ सहायता लें। |
| फिर इंस्टॉल करने पर भाषा नहीं बदली | मौजूदा उपयोगकर्ता की सहेजी पसंद स्थापना डिफ़ॉल्ट से ऊपर रहती है। साइडबार में झंडा बदलें। |
| डिफ़ॉल्ट भाषा कॉन्फ़िगरेशन अमान्य | ऐप बंद करके व्यवस्थापक से `powerportal-defaults.json` में समर्थित कोड वाला वैध UTF-8 JSON ठीक करवाएँ। |
| PowerShell स्क्रिप्ट अवरुद्ध है | इसकी समीक्षा करें और संगठन की निष्पादन नीति अपनाएँ। वैकल्पिक रूप से EXE विज़ार्ड उपयोग करें। कॉर्पोरेट नियंत्रण बंद न करें। |
| `-Silent` व्यवस्थापक PowerShell माँगता है | वह टर्मिनल बंद करें और PowerShell को **Run as administrator** से लॉन्च करके फिर प्रयास करें। |
| SHA-256 मेल नहीं खाता | **फ़ाइल न चलाएँ।** अमान्य डाउनलोड हटाएँ/दूसरी जगह रखें, आधिकारिक सामग्री फिर लें और प्रकाशित चेकसम से तुलना करें। |
| GitHub डाउनलोड विफल | कनेक्टिविटी, proxy/firewall प्रतिबंध और Release URL जाँचें। IT सत्यापित EXE स्वीकृत चैनल से वितरित कर सकता है। |
| PowerShell अंतर्निहित connection/TLS send त्रुटि देता है | Windows PowerShell में सहायक डाउनलोड करने से पहले दस्तावेज़ की TLS 1.2 पंक्ति उपयोग करें, फिर दोबारा कोशिश करें। मूल अनुप्रयोग अपडेटर पहले से HTTPS/TLS उपयोग करता है। |
| SmartScreen/अज्ञात प्रकाशक | 1.7.0 पर हस्ताक्षर नहीं है। चेकसम और प्रकाशक स्रोत जाँचें; यदि डिवाइस बिना हस्ताक्षर वाले प्रोग्राम रोकता है तो IT से पूछें। |
| Relationship editor केवल-पठन है | आयातित प्रोजेक्ट में केवल दृश्य व्यवस्था की जा सकती है। संबंध बनाने/संपादित करने/हटाने के लिए लाइव स्थानीय Power BI मॉडल से कनेक्ट करें। |
| पढ़ने के बाद संबंध बदल गया | Power BI मॉडल फिर पढ़ें और अद्यतन लिंक की समीक्षा करें। दूसरे बदलाव को अधिलेखित होने से बचाने के लिए पुरानी स्थिति वाले संपादन अस्वीकार होते हैं। |
| दोहरा या दूसरा सक्रिय संबंध | अलग कॉलम जोड़े चुनें, या उसी तालिका-जोड़ी का मौजूदा सक्रिय संबंध सक्रिय करने से पहले निष्क्रिय करें। |
| संबंध प्रकार/विशिष्टता/अस्पष्टता त्रुटि | कॉलम डेटा प्रकार मिलाएँ और Desktop में key/फ़िल्टर पथ देखें। TOM/Power BI मॉडल सत्यापित करते हैं; त्रुटि दरकिनार न करें। |
| आरेख सहेजना विफल | डिस्क स्थान और अनुप्रयोग प्रोफ़ाइल में लिखने की अनुमति जाँचें, फिर **Retry saving** करें। ज़रूरत हो तो अलग JSON प्रति निर्यात करें। |
| PBIX का नाम/प्रति बदलने के बाद आरेख अलग | प्रोफ़ाइल विंडो/फ़ाइल नाम और तालिका lineage tag उपयोग करती हैं; नाम/पहचान बदल या प्रतियों में टकरा सकते हैं। निर्यात लेआउट को इच्छित मॉडल में आयात करें। |
| स्टार्टअप पर अपडेट नहीं जाँचे जाते | 1.6.1 और पुराने संस्करणों के लिए 1.6.2 पर एक बार मैन्युअल अपडेट चाहिए। Development/source रन जानबूझकर अपडेट नहीं करता। |
| अपडेट जाँच विफल/ऑफ़लाइन/HTTP 403 या 429 | स्थानीय टूल उपलब्ध रहते हैं। इंटरनेट/proxy/firewall जाँचें और **Check for updates** दोबारा करें। GitHub API दर-सीमा लागू हो सकती है। |
| Update now चेकसम या आकार सत्यापन में विफल | इंस्टॉलर नहीं चलाया गया। फिर प्रयास करें या आधिकारिक Release मैन्युअल डाउनलोड करें; दूषित कैश फ़ाइल न चलाएँ। |
| Windows अनुमति रद्द की | Power Portal उपलब्ध रहता है। UAC की अनुमति देने को तैयार हों तो **Update now** फिर करें या स्थापना अनुमति के लिए IT से पूछें। |
| सक्रिय मॉडल कार्रवाई से अपडेट रुका | पुष्टि किया गया लेखन/theme कार्य पूरा होने दें, फिर कोशिश करें। अपडेट से पहले न भेजे संपादन सहेजें/निर्यात करें। |
| स्टार्टअप कनेक्शन सूचना नहीं आई | पहचान के लिए खुला स्थानीय semantic model चाहिए, केवल Desktop welcome screen पर्याप्त नहीं। PBIX खोलने के बाद **Find open models** चुनें। पहचान विफल हो तो दिखी त्रुटि जाँचें और पुनः कनेक्ट करें। |
| इंस्टॉलर चल रहे ऐप को बंद नहीं कर पा रहा | काम सहेजें, Power Portal स्वयं बंद करें और फिर प्रयास करें। केवल सटीक स्थापित निष्पादन योग्य लक्ष्य होता है। Power BI बंद नहीं होता। |
| ईमेल बटन कुछ नहीं करता | डिफ़ॉल्ट ईमेल क्लाइंट कॉन्फ़िगर करें, **Copy email** उपयोग करें या नीचे दिए पते पर स्वयं लिखें। |
| ऑनलाइन TV रिपोर्ट लॉगिन/लोड नहीं होती | Microsoft खाता, रिपोर्ट अनुमति, लाइसेंस, embedding प्रतिबंध और इंटरनेट जाँचें। ऑफ़लाइन TV प्रस्तुति के लिए स्थानीय चित्र उपयोग करें। |

## सहायता से संपर्क करें

ईमेल **[contato@consultoriaexcelencia.com.br](mailto:contato@consultoriaexcelencia.com.br)** करें या [WhatsApp पर Excelência से संपर्क करें](https://api.whatsapp.com/send/?phone=5535998532286&text&type=phone_number&app_absent=0)।

शामिल करें:

- Power Portal संस्करण (इस रिलीज़ के लिए 1.7.0)।
- Windows संस्करण और Power BI Desktop संस्करण/प्रकार।
- स्थापना विधि (विज़ार्ड या PowerShell)।
- दोहराने के चरण और दिखाई गई सटीक त्रुटि।
- एक या अनेक मॉडल खुले थे या नहीं।

**सार्वजनिक issue में PBIX/BIM फ़ाइल, स्रोत कनेक्शन विवरण, क्रेडेंशियल, गोपनीय डेटा या बिना छाँटे बैकअप/परिवर्तन लॉग कभी पोस्ट न करें।** स्क्रीनशॉट में भी नाम या डेटा दिख सकता है; साझा करने से पहले उन्हें छिपाएँ।

तैनाती और गोपनीय मामलों के लिए सार्वजनिक issue के बजाय सहायता ईमेल उपयोग करें।
