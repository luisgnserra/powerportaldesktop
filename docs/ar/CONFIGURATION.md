## تفضيلات اللغة والشريط الجانبي

استخدم أعلام الشريط الجانبي لتبديل اللغة. يُحفظ التفضيل في ملف تعريف التطبيق المحلي لمستخدم Windows. كما تُحفظ حالة طي الشريط الجانبي أو توسيعه.

تظل أزرار الأدوات الإحدى عشرة كلها ظاهرة دون تمرير الشريط الجانبي بأحجام النوافذ المدعومة. وتستخدم التسميات المحلية الطويلة سطرين مرئيين كحد أقصى مع الاحتفاظ باسم الوصول/التلميح كاملاً. تقع **Consulting and training** أسفل **About the development**. راجع [لقطات الشريط الموسع والمطوي](SCREENSHOTS.md#home-and-navigation).

ترتيب أولوية اللغة:

1. اختيارك المحفوظ في التطبيق.
2. ملف `powerportal-defaults.json` الخاص بالتثبيت.
3. لغة نظام Windows/Electron المحلية، والإنجليزية للغات غير المدعومة.

| الرمز | اللغة |
|---|---|
| `pt` | البرتغالية (البرازيل) |
| `en` | الإنجليزية |
| `es` | الإسبانية |
| `zh` | المندرينية / الصينية المبسطة |
| `fr` | الفرنسية |
| `ja` | اليابانية |
| `hi` | الهندية |
| `ar` | العربية، من اليمين إلى اليسار |

يكتب المثبّت هذا الملف في مجلد تثبيت التطبيق المحدد:

<div dir="ltr">

```json
{"language":"en"}
```

</div>

يمكن للمسؤول تحريره بعد إغلاق Power Portal لتغيير اللغة الافتراضية **لملفات تعريف المستخدمين الجدد**. احفظ JSON صالحاً بترميز UTF-8 يتضمن رمز لغة مدعوماً بالضبط. لا تحرر ملفات التطبيق الثنائية أو الموارد المضمّنة. تظهر رسالة واضحة عند وجود إعداد غير صالح.

لا يؤدي تغيير افتراضي التثبيت أو إعادة التثبيت إلى تجاوز اختيار العلم المحفوظ لمستخدم موجود. لا تُترجم أسماء النماذج أو البيانات أو الشيفرة أو تعبيرات DAX أبداً.

<a name="connect-to-an-open-power-bi-file"></a>
## الاتصال بملف Power BI مفتوح

الموصى به: افتح ملف PBIX في Power BI Desktop وشغّل **External Tools > Power Portal**. يمرر Desktop تلقائياً نقطة نهاية النموذج المحلي ومعرّف قاعدة البيانات.

إذا شُغّل التطبيق من اختصار Windows:

1. افتح PBIX في Power BI Desktop.
2. يظهر إشعار عند اكتشاف نماذج محلية مفتوحة. استخدم **Find open models** واختر اسم الملف.
3. استخدم **Read Power BI model** لإعادة تحميل البيانات الوصفية بعد التغييرات.

يقتصر الاكتشاف على عرض التوفر؛ ولا يحدد ملفاً تلقائياً ولا يكتب إليه. بعد الاتصال، تشير حالة خضراء مختصرة في الترويسة إلى التعديلات المؤكدة؛ استخدم **Refresh Power BI model** لإعادة تحميل البيانات الوصفية. [لقطات الاتصال](SCREENSHOTS.md#connect-to-a-file-already-open-in-power-bi).

إذا كان نموذج واحد مفتوحاً، يمكن للقراءة اكتشافه تلقائياً. وإذا كانت عدة نماذج مفتوحة، فحدد الملف المقصود صراحةً. تُميّز أسماء الملفات المتشابهة برقم؛ ولا تعرض عناوين نوافذ Power BI المسارات الكاملة دائماً.

الاتصالات محلية فقط. لا تُعِد إعداد خادم عام، ولا تشارك منفذ النموذج، ولا تعتبر التطبيق خادم DAX بعيداً. إذا أُعيد تشغيل Power BI، فاتصل بالنسخة المحلية الجديدة.

<a name="external-tools-registration"></a>
## تسجيل External Tools

يكتب المثبّت الملف التالي:

<div dir="ltr">

```text
%CommonProgramFiles(x86)%\Microsoft Shared\Power BI Desktop\External Tools\PowerPortal.pbitool.json
```

</div>

يتضمن التسجيل مسار الملف التنفيذي المثبّت وعناصر Desktop البديلة التالية:

<div dir="ltr">

```text
-- --powerportal-server "%server%" --powerportal-database "%database%"
```

</div>

وجود `--` في البداية مقصود. لا تحذفه ولا تستبدله بمنفذ قديم يدوياً. أعد تشغيل Power BI Desktop بعد تثبيت التسجيل أو إصلاحه.

<a name="data-locations"></a>
## مواقع البيانات

ملف تعريف التطبيق المعتاد:

<div dir="ltr">

```text
%APPDATA%\powerportal-desktop
```

</div>

تشمل المجلدات الفرعية المهمة ما يلي:

- `themes`: ملفات JSON المنشأة وصادرات التحقق `.applied.json`.
- `model-changes`: سجلات محلية لمحاولات الكتابة المؤكدة ونتائجها.
- `relationship-diagrams`: تخطيطات مرئية لكل نموذج، بما في ذلك أسماء الجداول/المجموعات والأيقونات والألوان والمواضع وإطار العرض. صدّر/استورد التخطيط من [Relationship map](RELATIONSHIPS.md#save-and-share-the-organization)؛ فهو لا يرسل كتابات إلى النموذج.
- `updates`: مثبّتات التحديث التي تم تنزيلها والتحقق منها. تُحذف التنزيلات الجزئية عند معالجة حالات الفشل. قد تبقى المثبّتات المتحقق منها بعد التثبيت؛ فلا تخلط بينها وبين نسخ النموذج الاحتياطية.
- يخزن الملف التعريفي أيضاً تفضيلات الواجهة لكل مستخدم.

تُخزن النسخ الاحتياطية للبيانات الوصفية محلياً ويظهر مسارها الدقيق بعد نجاح الكتابة. تُحفظ الوثائق المصدّرة والملفات المنزلة/المنشأة في الوجهة التي يحددها المستخدم.

تعامل مع النسخ الاحتياطية والسجلات والصادرات على أنها سرية: قد تتضمن نسخة BIM الاحتياطية الكاملة تفاصيل المصدر/الاتصال، وقد تحتوي سجلات التغييرات على DAX القديم/الجديد. لا تُحذف تلقائياً عند إلغاء التثبيت. لا ترفعها إلى issues عامة.

لإعادة ضبط تفضيلات الواجهة، اختر لغة أخرى أو وسّع الشريط الجانبي في التطبيق. قد تؤدي إعادة ضبط الملف التعريفي بالكامل إلى حذف السجلات والنسخ الاحتياطية المحتفظ بها أيضاً؛ فلا تحذف الملف التعريفي إلا بعد إغلاق التطبيق والاحتفاظ عمداً بكل ما تحتاج إليه.

<a name="network-and-accounts"></a>
## الشبكة والحسابات

- لا تتطلب المعاينات المحلية والأدوات المضمّنة حساب Power Portal.
- يتحقق التطبيق المثبّت من بيانات إصدارات GitHub العامة عند بدء التشغيل. وينزّل محدّث العملية الرئيسية الملفات الرسمية عبر HTTPS بعد **Update now**. لا تتضمن طلبات التحديث أسماء النماذج أو التعبيرات أو الصفوف أو بيانات الاعتماد.
- تحظر النوافذ المحلية التي تستخدم النموذج طلبات الويب البعيدة العشوائية.
- تفتح روابط الاستشارات والفيديوهات في المتصفح الافتراضي عند الطلب.
- يستخدم TV Tool نافذة عرض تقديمي منفصلة عبر الإنترنت لصفحات Power BI/Microsoft المنشورة. ولا يشارك الوصول إلى النموذج المحلي؛ كما أن تسجيل الدخول إلى Microsoft منفصل ولا يستمر بين الجلسات.
- قد تصل استعلامات DirectQuery إلى المصادر الأصلية عبر Power BI وقد تحتاج إلى الشبكة وبيانات اعتماد المصدر الحالية.
- يتطلب البريد الإلكتروني برنامج بريد مهيأ. استخدم **Copy email** إذا لم يتوفر.

لا توجد مفاتيح API أو كلمات مرور أو بيانات اعتماد للبوابة أو ملفات إعداد للشيفرة المصدرية يلزم توفيرها للتثبيت.
