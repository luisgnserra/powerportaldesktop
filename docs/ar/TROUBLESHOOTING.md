| المشكلة | الإجراء الموصى به |
|---|---|
| Power Portal غير موجود في External Tools | أكمل التثبيت بصلاحية المسؤول، وأغلق Desktop وأعد فتحه، وتحقق من [موقع التسجيل](CONFIGURATION.md#external-tools-registration). أصلح التثبيت بإعادة تشغيل المثبّت الرسمي. |
| لا يظهر شريط External Tools إطلاقاً | تحقق مع فريق تقنية المعلومات من إصدار/نسخة Power BI Desktop. تستهدف هذه الحزمة إصدارات Desktop التي تدعم الأدوات الخارجية، وليس Service أو Report Server. |
| لم تعد الأداة الخارجية تفتح | أعد تشغيل Desktop؛ فقد يكون الملف التنفيذي المثبّت قد نُقل أو حُظر. أعد التثبيت لإصلاح مساره. لا تحذف `--` الأول يدوياً من وسيطات التسجيل. |
| لم يُحمّل نموذج / فشل الاتصال | افتح PBIX في Desktop وشغّل من External Tools أو اختر **Find open models**. أعد الاتصال بعد إعادة تشغيل Desktop؛ فالمنافذ المحلية القديمة تنتهي صلاحيتها. |
| اسم الملف غير صحيح / نماذج متعددة | حدد النموذج المفتوح المقصود صراحةً وتحقق من هدف التأكيد قبل الكتابة. قد لا تتضمن عناوين النوافذ المسار الكامل. |
| فشل استيراد PBIX خام | افتح PBIX في Power BI واتصل محلياً. استخدم BIM/PBIP/TMDL/ZIP لاستيراد الملفات المدعوم للقراءة فقط. |
| ما زال مربع حوار theme يظهر | هذا متوقع: يستخدم استيراد theme في Desktop أتمتة واجهة مرئية. لا تتوفر في هذا الإصدار واجهة theme عامة مدعومة دون مربعات حوار. |
| فشلت أتمتة theme | احتفظ بملف JSON المنشأ، وتحقق من النافذة المستهدفة، وتجنب التفاعل أثناء الاستيراد، واستخدم قائمة Themes في Power BI للاستيراد يدوياً. أبلغ عن الخطأ الدقيق وإصدار Desktop دون رفع PBIX. |
| لم تُحمّل theme الحالية مع النموذج | احفظ JSON للـ theme الحالية في Desktop واستورده إلى مُنشئ theme. لا يستطيع TOM قراءة theme التقرير. |
| يوجد مقياس HTML لكن لا يظهر عنصر مرئي | أضف بنفسك عنصراً مرئياً متوافقاً مع HTML وعيّن إليه المقياس. |
| لا يحتوي التقويم على صفوف بعد | حدّث النموذج في Desktop ثم اقرأه مجدداً. تحقق من DAX/نطاق التاريخ. |
| رُفض التراجع عن التقويم | تغيّر الجدول أو أصبحت له تبعيات. لا تفرض الإزالة؛ استخدم نسخة PBIX المحفوظة أو اطلب المساعدة باستخدام نسخة البيانات الوصفية الاحتياطية. |
| لم تتغير اللغة بعد إعادة التثبيت | يتغلب اختيار المستخدم المحفوظ على لغة التثبيت الافتراضية. غيّر العلم في الشريط الجانبي. |
| إعداد اللغة الافتراضية غير صالح | أغلق التطبيق واطلب من مسؤول تصحيح `powerportal-defaults.json` إلى JSON صالح بترميز UTF-8 يتضمن رمزاً مدعوماً. |
| حُظر برنامج PowerShell النصي | راجعه واتبع سياسة التنفيذ لدى مؤسستك. ويمكنك بدلاً من ذلك استخدام معالج EXE. لا تعطّل الضوابط المؤسسية. |
| يطلب `-Silent` تشغيل PowerShell كمسؤول | أغلق الطرفية وشغّل PowerShell من **Run as administrator** ثم أعد المحاولة. |
| قيمة SHA-256 غير متطابقة | **لا تشغّل الملف.** أزل التنزيل غير الصالح/انقله، ونزّل الأصل الرسمي مجدداً وقارنه بقيمة التحقق المنشورة. |
| فشل تنزيل GitHub | تحقق من الاتصال وقيود الوكيل/جدار الحماية وعنوان URL لـ Release. يمكن لفريق تقنية المعلومات توزيع EXE المتحقق منه عبر قناة معتمدة. |
| يعرض PowerShell خطأ اتصال/TLS أثناء الإرسال | استخدم سطر TLS 1.2 الموثق قبل جلب المساعد في Windows PowerShell، ثم أعد المحاولة. يستخدم محدّث التطبيق الأصلي HTTPS/TLS بشكل مستقل بالفعل. |
| SmartScreen/ناشر غير معروف | الإصدار 1.7.4 غير موقّع. تحقق من قيمة SHA-256 ومصدر الناشر؛ واسأل فريق تقنية المعلومات إن كان جهازك يحظر البرامج غير الموقّعة. |
| محرر العلاقة للقراءة فقط | يتيح استيراد مشروع التنظيم المرئي فقط. اتصل بنموذج Power BI محلي مباشر لإنشاء العلاقات/تحريرها/حذفها. |
| تغيرت العلاقة منذ القراءة | أعد قراءة نموذج Power BI وراجع الرابط المحدّث. تُرفض التعديلات ذات الحالة القديمة لتجنب الكتابة فوق تغيير آخر. |
| علاقة مكررة أو علاقة نشطة ثانية | استخدم زوجاً مختلفاً من الأعمدة، أو عطّل العلاقة النشطة الحالية بين الجدولين قبل تفعيل علاقة أخرى. |
| خطأ نوع/تفرد/التباس العلاقة | طابق أنواع بيانات الأعمدة وافحص المفاتيح ومسارات التصفية في Desktop. يتحقق TOM/Power BI من النموذج؛ فلا تتجاوز الخطأ. |
| فشل حفظ المخطط | تحقق من مساحة القرص وأذونات الكتابة في ملف تعريف التطبيق، ثم استخدم **Retry saving**. صدّر نسخة JSON منفصلة عند الحاجة. |
| اختلاف المخطط بعد إعادة تسمية/نسخ PBIX | تستخدم الملفات التعريفية أسماء النوافذ/الملفات وعلامات lineage للجداول؛ وقد تتغير الأسماء/الهويات أو تتعارض بين النسخ. استورد التخطيط المُصدّر إلى النموذج المقصود. |
| لا تُفحص التحديثات عند بدء التشغيل | تتطلب الإصدارات 1.6.1 والأقدم ترقية يدوية لمرة واحدة إلى 1.6.2. ولا يحدّث تشغيل التطوير/المصدر التطبيق عمداً. |
| فشل التحقق من التحديث/دون اتصال/HTTP 403 أو 429 | تظل الأدوات المحلية متاحة. تحقق من الإنترنت/الوكيل/جدار الحماية وأعد **Check for updates**. قد تنطبق حدود معدل GitHub API. |
| فشل التحقق من قيمة SHA-256 أو الحجم في Update now | لم يُشغّل المثبّت. أعد المحاولة أو نزّل Release الرسمي يدوياً؛ ولا تشغّل ملفاً مخزناً مؤقتاً تالفاً. |
| أُلغيت صلاحية Windows | يظل Power Portal متاحاً. أعد **Update now** عندما تكون مستعداً للموافقة على UAC أو اسأل تقنية المعلومات عن صلاحية التثبيت. |
| منع التحديث بسبب عملية نموذج نشطة | انتظر انتهاء عملية الكتابة/theme المؤكدة ثم أعد المحاولة. احفظ/صدّر التعديلات غير المرسلة قبل التحديث. |
| لم يظهر إشعار الاتصال عند بدء التشغيل | يتطلب الاكتشاف نموذجاً دلالياً محلياً مفتوحاً، لا شاشة الترحيب في Desktop وحدها. استخدم **Find open models** بعد فتح PBIX. إذا فشل الاكتشاف، فتحقق من الخطأ المرئي وأعد الاتصال. |
| تعذر على المثبّت إغلاق التطبيق المشغّل | احفظ عملك، وأغلق Power Portal يدوياً، ثم أعد المحاولة. لا يُستهدف إلا الملف التنفيذي المثبّت المحدد. ولا يُغلق Power BI. |
| لا يفعل زر البريد شيئاً | أعد إعداد برنامج البريد الافتراضي، أو استخدم **Copy email**، أو أرسل يدوياً إلى العنوان أدناه. |
| تعذر تسجيل الدخول إلى تقرير TV عبر الإنترنت/تحميله | تحقق من حساب Microsoft وأذونات التقرير والترخيص وقيود التضمين والإنترنت. استخدم الصور المحلية للعرض دون اتصال في TV. |

<a name="contact-support"></a>
## التواصل مع الدعم

أرسل بريداً إلى **[contato@consultoriaexcelencia.com.br](mailto:contato@consultoriaexcelencia.com.br)** أو [تواصل مع Excelência عبر WhatsApp](https://api.whatsapp.com/send/?phone=5535998532286&text&type=phone_number&app_absent=0).

أدرج ما يلي:

- إصدار Power Portal (1.7.4 لهذا الإصدار).
- إصدار Windows وإصدار/نسخة Power BI Desktop.
- طريقة التثبيت (المعالج أو PowerShell).
- خطوات إعادة إنتاج المشكلة والخطأ المرئي الدقيق.
- ما إذا كان نموذج واحد أو عدة نماذج مفتوحة.

**لا تنشر أبداً ملفات PBIX/BIM أو تفاصيل اتصال المصدر أو بيانات اعتماد أو بيانات سرية أو نسخاً احتياطية/سجلات تغييرات غير منقّحة في issues عامة.** وقد تكشف لقطات الشاشة أسماءً أو بيانات أيضاً؛ فاحجبها قبل المشاركة.

للنشر والمسائل السرية، استخدم بريد الدعم بدلاً من issue عامة.
