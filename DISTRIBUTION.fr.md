Power Portal Desktop appartient à **Excelência Consultoria e Educação**.

Ce dépôt distribue le programme d’installation Windows officiel compilé ainsi que la documentation et les assistants d’installation associés. Il ne publie pas le code source de l’application Power Portal, et sa disponibilité sur GitHub ne rend **pas** l’application open source et n’accorde aucune licence open source.

Ce dépôt n’établit aucune nouvelle condition de licence pour l’application. Pour toute question relative aux licences, à la redistribution ou à l’utilisation commerciale, contactez **contato@consultoriaexcelencia.com.br**. Les conditions applicables existantes et les avis de tiers restent en vigueur.

Le programme d’installation présente les conditions des dépendances Microsoft AMO/TOM. Les avis de licence de tiers sont inclus avec les composants d’exécution installés. Microsoft, Power BI et Microsoft Fabric sont des marques de Microsoft ; l’identification MVP n’implique ni propriété, ni parrainage, ni approbation de Microsoft.

La version 1.8.0 n’est pas signée numériquement. Obtenez-la depuis les fichiers de la version officielle, vérifiez la somme SHA-256 publiée et respectez les politiques d’approbation des logiciels de votre organisation.

Les téléchargements ZIP/TAR « Source code » générés automatiquement par GitHub contiennent uniquement les fichiers de ce dépôt de distribution. Ils ne constituent ni l’application Power Portal, ni un programme d’installation, ni une publication du code source de l’application.
