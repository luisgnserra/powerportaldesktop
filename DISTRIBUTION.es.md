Power Portal Desktop pertenece a **Excelência Consultoria e Educação**.

Este repositorio distribuye el instalador oficial compilado para Windows y la documentación y los asistentes de instalación relacionados. No publica el código fuente de la aplicación Power Portal, y su disponibilidad en GitHub **no** convierte la aplicación en software de código abierto ni concede una licencia de código abierto.

Este repositorio no establece nuevas condiciones de licencia para la aplicación. Para consultas sobre licencias, redistribución o uso comercial, contacte con **contato@consultoriaexcelencia.com.br**. Siguen vigentes las condiciones aplicables existentes y los avisos de terceros.

El instalador presenta las condiciones de las dependencias Microsoft AMO/TOM. Los avisos de licencia de terceros se incluyen con los componentes de ejecución instalados. Microsoft, Power BI y Microsoft Fabric son marcas comerciales de Microsoft; la identificación MVP no implica propiedad, patrocinio ni respaldo de Microsoft.

La versión 1.7.0 no está firmada digitalmente. Obténgala de los recursos oficiales de la versión, verifique la suma SHA-256 publicada y cumpla las políticas de aprobación de software de su organización.

Las descargas automáticas ZIP/TAR de «Source code» de GitHub contienen únicamente los archivos de este repositorio de distribución. No son la aplicación Power Portal, un instalador ni una publicación del código fuente de la aplicación.
